# Repository instructions

## C# code style

- Always use braces for `if`, `else`, `for`, `foreach`, `while`, and `do`, even when the body contains only one statement.
- Prefer compact expressions and argument lists when they remain readable. Do not place every argument or nested expression on its own line unnecessarily.
- Keep straightforward calls and declarations on one line. Split long code only when doing so materially improves readability.
- Apply these rules consistently to both production code and tests.
